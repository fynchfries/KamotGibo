# KamotGibo

[Download the cinematic video demo](https://github.com/fynchfries/kamotgibo/raw/refs/heads/main/kamotgibo-demo-cinematic.mp4)

A **60-second, 1080p** MVP walkthrough with cinematic zooms, camera pans, and view transitions. No captions or audio.

The demo covers workshop discovery and booking, artisan approval and publishing, attendance, skill badges, and upskilling.

This repository contains the video demo only. The app uses fictional sample data; bookings and approvals are simulations.
